# Contributing

Thank you for contributing to EV-Decision-2027.

The primary objective of this project is transparency and reproducibility.

## General Rules

### Facts

Objective data must originate from reliable sources.

Examples

- battery capacity

- charging power

- dimensions

---

### Ratings

Subjective ratings must include

- explanation

- source

- review date

---

### Sources

Preferred

- official documentation
- independent testing
- long-term reviews

Avoid

- marketing material
- unsupported opinions

---

## Git

Keep commits focused.

Good

```
docs: improve scoring documentation
```

Bad

```
Update everything
```

---

## Discussions

Constructive criticism is welcome.

Evidence always has priority over opinion.
