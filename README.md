## Vision

Choosing an electric vehicle is becoming increasingly difficult.

Most comparison websites focus on manufacturer specifications, acceleration figures or range. However, real purchasing decisions often depend on many additional aspects:

- Driver assistance quality
- Charging behaviour
- Software maturity
- OTA strategy
- Vehicle-to-Load capability
- Long-term usability
- Local service availability

EV-Decision-2027 aims to provide a transparent, explainable and reproducible evaluation framework that combines objective technical data with documented real-world experience.

The project is designed to support evidence-based vehicle comparisons rather than subjective rankings.

---

## Goals

- Transparent evaluation methodology
- Explainable scoring
- Evidence-based assessments
- Reproducible results
- User configurable weighting
- Long-term maintainability

---

## Core Principles

- Objective data and subjective ratings are stored separately.
- Every subjective score requires a documented justification.
- Every assessment includes a confidence level.
- Marketing claims are never treated as verified facts.
- OTA updates may change vehicle ratings over time.

---

## Scoring Model

Each vehicle receives four independent scores.

| Score | Description |
|--------|-------------|
| Technical Score | Objective technical capabilities |
| Profile Score | Suitability for a specific user profile |
| Future Score | Expected long-term potential |
| Confidence Score | Reliability of the current assessment |
